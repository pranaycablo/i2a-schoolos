# 🎨 i2A SchoolOS — Centralized Branding Engine & Document Preview Specification
> **Dynamic Branding Configuration & Multi-Channel Asset Propagation**

## 📌 Branding Configuration Entity

- `logoUrl`, `stampUrl`, `principalSignatureUrl`, `primaryColor`, `secondaryColor`, `invoiceHeader`, `invoiceFooter`, `reportCardTheme`, `certificateTheme`.
- **Validation**: Strict file format checks (PNG, JPG, WEBP, sanitized SVG) and safe storage key creation.
- **Dynamic Propagation**: Real-time rendering on fee receipts, report cards, ID cards, bonafide certificates, and public website.
