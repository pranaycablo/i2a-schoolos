# 👩‍🏫 i2A SchoolOS — Teacher Specialization Model Architecture
> **Staff Extension, Specializations & Teaching Assignments**

---

## 📌 Model Specification

- **Teacher Extension**: Extends `Staff` entity (`specializations`, `qualifications`, `assignedSubjects`).
- **Specialization Rule**: Subject specialization does NOT grant automatic academic access; explicit class/section assignment is mandatory.
